Modeling coverage, provenance, and honest execution depth

This strand contains 18 original guided notebooks, totaling roughly 10,000 words of original explanatory teaching text plus code, prompts, checks, and answer keys. It expands the earlier six-lesson strand. The sources below were inspected as actual repository curricula and tutorial notebooks; topic names were not inferred from USC course numbers. A detailed public NIIN 550 syllabus still was not located. This is a neuroimaging-focused synthesis, not a claim to reproduce USC's weekly teaching or to replace its degree.

The selected source curricula are broader than this strand. Neuromatch also covers cellular models and reinforcement learning; those topics are deliberately outside this imaging-analysis course. Conversely, imaging-specific measurement, preprocessing, study design, and foundational statistics are handled in the other strands. The table makes external continuations and missing execution explicit rather than implying that one toy example covers an entire method.

These are synthetic mechanics labs, including genuine fitted models and neural-network optimization where stated. No source notebook is treated as a finished student submission; some intentionally contain incomplete exercises.

Required evidence before calling an extension complete

A learner should keep the original upstream notebook, make a separate working copy, record its commit and dataset version, execute the prerequisite data setup, complete the exercises, and save results plus a failure analysis. A verified install is not a completed analysis. Record downloaded data licenses separately from the software or teaching license, and state whether a GPU or distributed processing was required. Do not upload participant data to an assistant merely because an upstream notebook contains a download link.

For each real-data continuation, deliver: input identities and consent/access constraints; meaningful unit and split; fitted-transform record; expected-versus-observed checks; figures with spatial/timing context; error or failure investigation; and a result claim limited to the evaluation performed. The local core can prepare the reasoning, but cannot supply those missing observations.
