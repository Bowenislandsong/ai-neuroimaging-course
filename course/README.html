Introductory supplement. The current course begins with R00, uses the 26-week study plan, and includes 83 notebooks. This page collects the earlier short-format lessons for reference.

AI-assisted neuroimaging: understand every transformation

A beginner course for a learner who uses AI to write short analysis snippets and wants to understand, inspect, and defend what those snippets do.

For this retained supplement: Setup and the AI teaching contract, then two foundation classes. The complete reading edition collects its teaching text in one file. The four notebooks contain the executable demonstrations; their HTML companions show the verified outputs without installing Python. The current course instead starts with the paper seminars linked above.

Supplement structure

This collection has 24 core classes, two foundation classes, and two capstone sessions. Its original 14-week schedule uses two 60–75 minute classes per week, plus 30–60 minutes of practice.

The four blocks follow the broad subject areas of USC's NIIN curriculum. Their lessons and assignments were developed for this course; source records identify the teaching materials used.

Learning outcomes

Students explain a transformation's inputs, outputs, units, information loss, likely failure, and relevant checks. They can ask an AI to implement a step, inspect the result, and assess its scientific interpretation.

The rule for every class

Predict → ask AI for one small operation → inspect code → run → compare → explain. No points for the number of lines she writes. Keep the answer key closed until she explains the result. Use short prompts from the lesson, and paste the tutor contract into each fresh AI conversation.

Every class has an explanation, a concrete experiment, an intentional mistake, expected checks, and exit questions. Code cells are short; some experiments need several cells. A successful run is one piece of evidence, not automatic validation.

Materials included

  • Setup, transformation reference, and glossary.
  • Original lesson text and four offline synthetic notebooks; all needed toy data are generated in the cells.
  • Transformation card, analysis record, project plan, and assessment rubric.
  • Primary-source reading links and an optional real-data bridge. External books, slides, scans, and model weights are linked rather than bundled.
  • Verification report documents what was executed. Local AI setup is documented, not installed or benchmarked on her hardware.

The runnable core uses small synthetic arrays so she can see the correct answer. It does not perform research-grade MRI preprocessing. The real-data stage uses an existing documented teaching pipeline; an instructor reviews the acquisition, processing, and inference decisions.
